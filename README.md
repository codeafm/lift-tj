# Lift TJ

Сайт компании Lift TJ — продажа, монтаж и сервис лифтов в Таджикистане.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации: `npm run build` (результат в `dist/`).

## Где что менять

- `src/data.js` — телефон, адрес, каталог лифтов, объекты, этапы, FAQ.
- `src/OrderForm.jsx` — форма заказа: заявка отправляется в WhatsApp готовым сообщением.
- `src/App.jsx` — разделы страницы.
- `src/App.css`, `src/index.css` — дизайн (цвета задаются переменными в `:root`).
- `public/images/` — фотографии лифтов и объектов.
